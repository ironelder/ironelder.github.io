Android 앱의 화면부터 아키텍처까지 클라이언트 전반을 다룹니다. 요즘은 오래된 Java 코드를 Kotlin 으로 옮기고, 모듈과 레이어 경계를 정리해 바꾸기 쉬운 구조로 만드는 일에 시간을 많이 쓰고 있습니다.

AI 도구를 개발 흐름에 붙이는 실험도 즐깁니다. 코드 리뷰, 정적 분석 이슈 수정, 빌드 확인처럼 매번 반복되는 일을 자동화하며 배운 것을 정리해 나갈 예정입니다.

Kotlin First

Java 레거시를 Kotlin 으로 옮기며 null 안전성을 지키는 코드를 씁니다.

Clean Architecture

레이어와 모듈 경계를 나눠 기능을 안전하게 바꿀 수 있게 만듭니다.

Jetpack Compose

XML 화면을 Compose 로 옮기며 선언형 UI 를 다룹니다.

AI × Dev

Claude Code 같은 AI 도구로 리뷰·빌드·반복 작업을 자동화합니다.
